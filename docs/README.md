# Solar Forge Life Helper documentation

Solar Forge Life Helper is a local Python/PySide6 desktop app for everyday planning and tracking. Its modules share one account-based SQLite database. The app runs from source or in Docker on a Linux Wayland desktop.

## Start here

- [Getting started](getting-started.md): launch the app and create your first account.
- [Using the app](user-guide.md): navigate the dashboard and use each module.
- [Data and migration](data-and-migration.md): find, move, and back up your data.
- [Development](development.md): project layout, checks, and contribution workflow.

The [repository README](../README.md) has a short project summary and launch commands.
